## A. 棘轮手感（社区配方，电源到货后第一个升级）

来源：SimpleFOC 社区 schoch 的 haptic textures + scottbez1/smartknob。
力矩(电压)模式下三行公式：

```cpp
// 设定：detent_count = 每圈档位数(如 8)，强度 stiffness = 10~40
float detent_angle = 2.0f * PI / detent_count;          // 每档弧度宽

// loop() 里（loopFOC 之后）：
float attractor = round(motor.shaft_angle / detent_angle) * detent_angle;  // 最近的档位中心
motor.move((attractor - motor.shaft_angle) * stiffness);                   // 拉回档位的电压
```
- `stiffness` = 刚度：小=软阻尼感，大=硬棘轮咔哒感。**先从 15 起调**
- 移植进 knob.cpp 时注意：knob 目前无电机，需新增 driver+motor 对象并把 `sensor.update()` 的职责交给 `loopFOC()`

## B. 两轴云台（P2）的三个决策点

1. **第二个电机** = 再建一套 `BLDCMotor + BLDCDriver3PWM` 实例（引脚换 TIM1 备用通道或 TIM8），两个 `loopFOC()` 同循环调用，I2C 读角共用
2. **第二个编码器是真难点**：AS5600 地址固定 0x36，一条 I2C 总线挂两个会冲突。三个方案：
   - 换一个 AS5600 做模拟输出模式（MagneticSensorAnalog）——推荐，零冲突
   - 用 MagneticSensorPWM 模式（占一个 GPIO 捕获脚）
   - 换 MT6701 等可设地址的编码器（SSD1306 同时在总线上也需确认无冲突）
3. **控制率**：两路 loopFOC + 串口协议解析，主循环预算 ~1ms，协议解析保持非阻塞

## C. Commander 调试接口（closedloop.cpp 已在用）

```cpp
#include <SimpleFOC.h>
Commander command = Commander(Serial);

void doLimit(char* cmd) { command.scalar(&motor.voltage_limit, cmd); }  // "L 5.0" → 限压 5V

void setup() {
    ...
    command.add('L', doLimit, "voltage limit");
    command.add('m', doMode, "control mode");
    motor.useMonitoring(Serial);   // 让 motor 监视输出走串口
}

void loop() {
    ...
    motor.move(motor.target);
    command.run();                 // 处理串口命令
    motor.monitor();               // 按 monitor_variables 位图打印目标/电压/速度/角度
}
```
- `motor.monitor()`：串口绘图仪神器，Arduino IDE 的 Serial Plotter 直接连线看 PID 响应
- `monitor_variables` 位图可选打印项：`_MON_TARGET | _MON_VOLT_Q | _MON_VEL | _MON_ANGLE`
