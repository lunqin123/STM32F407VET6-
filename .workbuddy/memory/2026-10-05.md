## 《底层经典问题集.md》卡片式重排

用户反馈"排版太烂"。原排版问题诊断：段落式密集块 —— 元信息/面试官/得分点/追问全部挤进无空行的连续行，
93 题无任何索引，扫读与跳转都困难。

处理方式：**不做手工重写，改为写脚本转换** —— 1600+ 行、93 题手工重试必然丢内容。
- 新工具：`tools/reflow_interview_bank.py`（每次运行自动备份到 `archive/`，带时间戳）
- 自动识别 `### Qn.` 块，拆成：标签行（`★★★` / `岗位`）→ 面试官引用块 → 编号得分点（词组加粗做左列锚点）
  → 问答分离的追问链（`- **问？** → 答`）→ 加分/避坑分列 → 自测勾选行
- 顺带自动重建**顶部索引区**：元信息表 + 11+1 模块目录 + ★★★ 速查表（67 题，双列紧凑表）+ ★★ 补充表（26 题）
- 结果：93 题全收，行数 1637 → 2637（呼吸感换来的）

### 约束与经验
- **保持行首形式不变是解析前提**：得分点必须 `①` 开头、追问必须 `→` 开头、加分/减分必须 `**★加分` 开头。
  以后手改题库要沿用这套行首格式，否则脚本会漏。
- **题号不补零**：正文里有大量交叉引用（"见 Q59"、"接 Q35"），补零会全部失效。
- **Write 工具写入含中文引号的 Python 字符串会被转成 ASCII 引号** → 直接 syntax error。
  教训：脚本里中文引语一律用「」不用 ""。
- Bash 环境缺 coreutils：`dirname`、`wc`、`head` 都不可用 → 这类统计要用 Read/Grep 替代。
