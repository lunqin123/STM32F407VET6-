## 底层原理讲解：为什么配置地址就能实现功能（MMIO / GPIO）
- 用户问"为什么配置一个地址就能实现对应的功能，比如 GPIO"。用 3 张 SVG 图解（总线译码链路 / MODER 位选通 MUX / 地址基址+偏移拆解）+ 代码回答。
- 讲解口径（可复用）：① Cortex-M 统一编址，无 in/out 指令，内核只发地址+数据+控制，译码器（与门组合逻辑）比对高位地址拉片选；地址空间稀疏，未实现地址 → BusFault/HardFault ② 寄存器位 = 硬连线控制端，MODER 两位是 MUX 选择线（00输入/01输出/10复用/11模拟），OTYPER 决定 P-MOS 是否参与（开漏是 I2C 线与基础），PUPDR 接通 40kΩ 上下拉，BSRR 原子置位/复位避免读改写竞争，IDR 有 1~2 个 APB 时钟同步延迟 ③ 地址 = 高 16 位选外设 + 低 16 位选寄存器偏移。
- 两个必讲坑：volatile（否则编译器删/合并"无用"写）、RCC 时钟门控未开 → 触发器无时钟沿且总线接口不响应，写被静默丢弃（"代码没错但灯不亮"首因）。
- 补充：F407 位带别名词基址 0x42000000，公式 `0x42000000 + (addr-0x40000000)*32 + bit*4`；实用场景多用 BSRR。
