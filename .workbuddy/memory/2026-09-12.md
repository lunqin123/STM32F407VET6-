### 1. 固件改造 `src/closedloop.cpp`（编译通过，Flash 16.1%）
- 新增 **`O<ms>` 遥测命令**（0=关，**默认关闭**，自动抬到最小 5ms/200Hz）
  - 行格式：`D,<ms>,<mode>,<target_rad>,<angle_rad>,<velocity_rad_s>`
  - 单缓冲一次 `Serial.write`（**不用**内置 `motor.monitor()`：它按变量分多次 print，库源码自注 "significantly slowing the execution down"）

### 2. 新工具 `tools/serial_bench.py`（自动测试台）
- **零额外依赖**：仅 pyserial + 标准库（本机 managed python 3.13.14 **无 numpy/matplotlib** → 出图自绘 SVG）
- 6 个子命令：`step`（位置阶跃）/ `velstep` / `hold`（恒速稳定性）/ `repro`（可复现性 N 次 + CV 离散度）/ `raw` / **`selftest`（无硬件自检）**
- `--set` 可重复下发任意固件命令（`--set F0.05 --set A15`）→ 整定矩阵可脚本化；`--limit` 固定电压上限保证可比
- 指标：上升时间(10-90%)、超调、调节时间(±band)、稳态误差、纹波 pp/RMS；`repro` 输出均值/极值/标准差/CV
- 产物：`tools/runs/<时间戳>_<测试>.csv`（带 `# key=value` 元数据）+ `.svg`；退出/中断自动发 `O0` 关遥测
- **★ 时间轴精度设计**：阶跃时刻由**遥测里 `target` 字段变化**判定（设备侧），非主机发送时刻 → 不受 USB 延迟影响，分辨率 = 遥测周期

| 同上只看速度读数 | 抖动 ±0.5 rad/s RMS | **测量噪声**（编码器 0.088° 被微分放大），≠ 机械抖动 |
| 位置模式阶跃 A=20 | **±9.6° 真实机械振荡** | **位置环闭合成环后才出现** → 位置环是激发源 |
- 用 `screen_step.py` 复测（4~6 次/组）：**A=20 四跑四振、六跑六振**（确定行为，不是偶发）

**④ 两个杠杆的实测边界（L=2V、V=3）**
- **位置环 `A`**：边界 **13~16**（A16 双稳态、A13 稳）；**旧默认 20 在边界之外**
- **速度反馈滤波 `F`**：A=20 时边界 **0.03~0.06**；**F≥0.06 可单独救回 A=20**
- 机制：**位置环把速度反馈里的噪声放大成自持极限环** —— 降 A 减放大倍数，加 F 削噪声源

**⑤ ★ 定稿（已写入固件默认值 + 烧录 + 同步 SAFE_PARK）**
```
L=2V   V=3 rad/s   P_velocity=0.5   I_velocity=10   F=0.05   A_angle=10
```
- 90° 阶跃（6 次复现全过）：**上升 ~450ms / 超调 ~0.1% / 调节 ~707ms / 纹波峰峰 ≤0.17°**
- 裕量：A=10 对边界 13~16（≈2×）；F=0.05 对边界 0.03

**⑥ 两个"假阳性"（方法论，比参数值钱）**
1. **`SAFE_PARK` 漏 `A` → 污染整轮扫描**：`screen_step` 顺序跑 `-`→`V2`→`A8`→`I5`→`F0.06` 时，
   `A8` 之后 A 一直是 8 且从未还原 → **`I5`/`F0.06` 的"干净"其实全是 A=8 带来的**，与 I/F 无关。
   → 铁律：**凡是能改到电机动态的参数都必须列入 SAFE_PARK；扫描时差异参数必须显式写出**。
2. **L1 判据不测纹波 → 极限环反而"三项全过"**：极限环的三项指标极其重复（CV 很小），
   工具打印了"✓ 三项全过：可以写进简历"，而机器其实在持续振 20°。
   → 已在 `serial_bench.py` 增设**纹波绝对判据**（峰峰 max ≤ 1°，且**不适用 CV**）；判据三项→四项。

**⑦ 被推翻的旧假说（留档防再犯）**
| 旧假说 | 复测结果 |
|---|---|
| 真凶是**速度环饱和**（`P_vel×V>限压`）→ 要 `V≤4` | **伪**。A 仍 20 时单独把 V 降到 2 **仍四跑三振**；V 不是主因 |
| `V=3` 是定稿关键参数 | V 只决定阶跃**斜率**（上升时间）；保留 3 是为响应速度，**非"防饱和"** |
| §14 那组（A=20）已稳定 | **伪**。单次侥幸；A=20 实为持续振荡点 |

**⑧ 元教训（本机是双稳态系统）**
同一组参数会在「干净衰减」与「自持 ~19 Hz 极限环」之间跳（实测同参数一次 0.0°、一次 21°）。
→ **今后任何"稳定/不稳定"的结论，必须由 ≥6 次重复的 min/max 支撑**（`tools/screen_step.py`）。
   这条纪律本身即最佳面试素材："我不信单次漂亮波形，我写了个筛选器量化离散度。"
